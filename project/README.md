### My Responsibility
I am responsible for the Database and RAG parts of the GreenField AgroWorks project.

### Database Work
- Designed the database schema.
- Created the seed data.
- Designed the Entity Relationship Diagram (ERD).
- Defined the main entities and their relationships.
- Worked with farm, field, crop, chemical, worker, application, and approval data.

### Safety Support
The database supports the safety workflow by storing information related to:
- Restricted chemicals
- Worker certification
- Chemical application requests
- Approval records

Restricted chemical applications require approval from a certified worker.

### RAG Contribution
I contributed to the RAG knowledge base for chemical safety information.

The knowledge base contains unstructured safety information such as:
- Restricted chemical approval requirements
- Chemical re-entry intervals
- Pre-application safety checks
- Human approval requirements
- Incident reporting procedures
